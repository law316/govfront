# govfront
React 19.3 + Vite 8.3 frontend for Vercel.

Local:
1. Copy `.env.example` to `.env`.
2. Set `VITE_API_URL=http://localhost:8080`.
3. Run `npm install`
4. Run `npm run dev`

Production:
Set `VITE_API_URL=https://YOUR-FLY-APP.fly.dev`.
Keep `VITE_OFFICIAL_AFFILIATION=false` until official programme authorization is verified.
